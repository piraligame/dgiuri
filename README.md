# WEEKLY+ 0.20 Android TEST

Debug APK (ge.weeklyplus.app.test; versionCode 12) installs alongside the Play app and does not update it.

Functions: year calendar with 12 mini-months, actual Android home widget, native PIN/biometric gate for private journal, Android Keystore AES-GCM note encryption, pinned notes, categories, file attachment via SAF, original task planner and alarms.

This is a developer test build. Device validation is still required; do not treat it as a production release.
